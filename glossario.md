# Glossário Versionamento 
## Definição das palavras 

**1. Git:** É um sistema de controle de versões que permite acompanhar as alterações feitas em arquivos e projetos ao longo do tempo. Com ele, é possível voltar a versões anteriores e trabalhar em diferentes partes de um projeto.

**2. GitHub:** É uma plataforma online que permite armazenar repositórios Git e compartilhar projetos com outras pessoas. Também facilita o trabalho em equipe e o controle das alterações.

**2.1. Diferença entre Git e GitHub:** O Git é a ferramenta que controla as versões dos arquivos, enquanto o GitHub é uma plataforma que permite armazenar esses projetos na internet e colaborar com outras pessoas.

**3. Repositório:** É o local onde ficam armazenados os arquivos de um projeto e seu histórico de alterações. Pode ser criado no computador ou em plataformas como o GitHub.

**4. Commit:** É um registro de uma alteração feita no projeto. Cada commit salva um conjunto de mudanças, permitindo acompanhar o que foi modificado ao longo do desenvolvimento.

**5. Branch:** É uma ramificação do projeto que permite desenvolver novas funcionalidades ou fazer alterações sem modificar diretamente a versão principal.

**6. Main:** É o nome geralmente utilizado para identificar a branch principal de um projeto. Nela fica a versão principal do código, que reúne as alterações consideradas importantes, lá é guardada a versão principal de um projeto 

**7. Merge:** É o processo de unir as alterações de uma branch com outra, permitindo juntar diferentes partes do desenvolvimento em um único projeto.

**8. Pull Request:** É uma solicitação feita para que as alterações de uma branch sejam analisadas e depois incorporadas a outra branch. É muito utilizado no GitHub para organizar e revisar o trabalho em equipe.
